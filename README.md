功能：通过光照采集和串口发送指令控制舵机角度
使用外设：UART，I2C，ADC，PWM
设计思路：
创建了四个任务分别是ADC，串口，舵机与OLED显示；
创建了两个队列，队列一用于传递控制舵机的值，队列二传递ADC的值用于OLED显示；
枚举定义了一个状态量来切换光照与串口模式，随着状态改变队列一可以接收来自ADC与串口任务的值，且收到值都经过处理可以直接用于舵机控制；
创建了一个二进制信号量用于检测串口中断，未收到消息时串口任务处于阻塞态，不占用资源；
每个任务单独创建.c文件。
收获：
实际运用了FreeRtos，稍微理解了模块化的意义，起初由于我认为ADC与串口给出同一个数据，想写成一个任务，后面理解到有必要将他们分开，除了任务优先级的考量以外还方便后续修改；
首次尝试将各外设综合起来并相互关联，对cubemx运用更熟练；
遇到问题比如用到printf而没有重定向导致程序卡死，OLED任务栈大小不够，串口指令检测不到\n于是改为h结尾；
学到如外部声明，枚举定义的处理方式
